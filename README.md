# 📦 Pictogrammer - PWA App

En mobilapp til at bygge pictogrammer strukturer med drag & drop!

## 🚀 Installation på telefonen

### Android
1. Åbn Chrome eller en anden browser der understøtter PWA
2. Gå til mappen hvor `index.html` ligger (eller host den på en webserver)
3. Når du åbner siden, skal du se "Installer app" eller et plus-ikon i addresslinjen
4. Tryk på det og bekræft
5. Appen er nu installeret på din telefon! 📱

### iPhone/iPad (iOS)
1. Åbn siden i Safari
2. Tryk på "Del"-knap (pil-ikonet)
3. Scroll ned og vælg "Tilføj til Startskærm"
4. Giv appen et navn og tryk "Tilføj"
5. Appen er nu på din startskærm! 📱

## ✨ Features

✅ **Drag & Drop** - Flyttes rundt med musen eller fingeren
✅ **Bibliotek** - 60 færdige pictogrammer
✅ **Upload** - Upload dine egne billeder
✅ **Canvas** - Byg dine strukturer
✅ **Gem Layouts** - Gem dine arbejder
✅ **Offline** - Virker uden internetforbindelse
✅ **Responsiv** - Virker på alle enheder

## 📱 Telefon Tips

- **Træk elementer** - Hold finger på element og drag
- **Slet** - Vælg element og tryk slet-knappen
- **Rolle rundt** - Der er mange funktioner i sidebars, scroll for at se mere
- **Download** - Hent dit arbejde som billede

## 🔧 Teknologi

- HTML5
- CSS3
- Vanilla JavaScript
- Service Workers (offline support)
- Progressive Web App (PWA) teknologi

## 💾 Dine Data

Alle dine layouts bliver gemt lokalt på enheden i browser-lageret. De synkroniseres ikke til cloud, så de er kun på din telefon.

## 🐛 Fejlrapportering

Hvis noget bugger, kan du:
1. Ryd browser cache (Settings > Apps > Pictogrammer > Storage > Clear Data)
2. Geninstaller appen
3. Eller prøv i en anden browser

Enjoy! 🎉
